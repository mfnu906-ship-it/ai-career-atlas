# Revision plan

This page tracks the agreed changes for the next AI Career Atlas release. Items are based on the feedback in this project conversation and the repository's GitHub issue tracker. The repository had no GitHub issues when this plan was drafted on November 5, 2026, so the conversation feedback is recorded below rather than presented as existing issues.

## Current release baseline

- The VitePress site is published through GitHub Pages.
- The site has no sidebar, following the preferred first version.
- The role map includes concise bullet summaries for forward deployed engineer, AI engineer, and AI evaluation engineer.
- The top navigation links to role exploration, research notes, this revision plan, and the source repository.

## Next release: research and content pass

### Role coverage

- [ ] Review whether the current role set reflects the range of emerging AI work; add roles only when job-description evidence supports a useful distinction.
- [ ] For each role, clarify its core outcomes, typical responsibilities, adjacent titles, and how it differs from neighboring roles.
- [ ] Add representative job-description examples with employer links and an observed date; summarize postings in our own words and note when a link is no longer active.

### Sources and freshness

- [ ] Check every external source link and confirm that each role summary is supported by current employer or other primary sources.
- [ ] Add a visible “last reviewed” date to role and research pages.
- [ ] Establish a lightweight release review: refresh sources, remove expired examples, check navigation and page links, then build and publish.

### Site experience

- [ ] Keep the current no-sidebar layout unless later feedback asks for a different navigation pattern.
- [ ] Review the site on mobile and desktop, including the top navigation and role-map bullets.
- [ ] Keep the Revision plan linked in the site menu and update this checklist as work is completed.

## Feedback and decisions recorded

- **Navigation:** the sidebar was explored, then removed at the user's request. The current release should stay sidebar-free.
- **Role overview:** concise bullets for the three existing roles were requested and added to the role map.
- **Release tracking:** this Markdown plan and its site-menu link were requested so future changes can be tracked in one place.
